# 轮胎动态、尾焰、烟尘与电机声实测

2026-10-29。H5 和小游戏共享独立车身+4轮，轮胎8个缓存纹理相位随真实位移变化，前轮同向偏转、内轮偏角更大。减速、停止、眩晕、失联及新局不会留下空转。烟尘上限96，约0.32–0.44秒淡出；减少特效模式不生成烟尘。冲刺有队伍色外焰、橙/金/白色内焰和速度线。

## 证据

- h5-driving.png：行驶与轮胎烟尘。
- h5-turning.png：实际转向，前轮与车身有独立偏角。
- h5-boosting.png：冲刺状态和多层尾焰。
- h5-motion.webm：真实游戏Canvas连续录制，包含驾驶、转向、冲刺与停止；无音轨，不是效果图或合成动画。
- h5-runtime.json：实际4轮精灵的位置/角度/帧、受限烟尘数量，以及AudioContext处于running状态时循环声启动/停止记录。
- native-*-bridge.png：实际小游戏包在wx浏览器桥接环境的运行截图，不是微信真机截图。
- native-runtime.json：相同轮胎视觉及音频池的播放、循环和停止记录。测试适配器通过真实HTMLAudio解码/播放打包WAV，不能代替微信原生真机听感验收。

## 验证结果

184项客户端测试、两端TypeScript检查与构建通过。测试包括位移驱动、前轮偏角符号、跳变/过期/复位、精灵复用/回收、烟尘上限/过期，以及声音循环/静音/后台生命周期。小游戏主包1303KiB，总包3981KiB，art2677KiB。高分辨率母版未进入运行包。

独立代码复查无阻断问题；发现最小车身比例0.25下普通速度先触及轮胎帧率上限，导致冲刺无法继续加快。将其作为加速反馈一致性问题修复，新增测试先失败再通过；改为平滑饱和曲线，所有支持比例都能继续区分普通移动与冲刺。

加速音为原创合成boost-engine.wav，起音5ms，H5使用0.08–0.48秒的稳定循环区及0.65增益；小游戏使用完整0.48秒电机样本及0.7音量，游戏声音开时obeyMuteSwitch=false，游戏声音总开关依旧有效。没有修改服务器规则。手机媒体音量和最终听感请用户用真机验证。
