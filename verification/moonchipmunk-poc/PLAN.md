# MoonChipmunk 验证计划
1. 锁定游戏、镜像来源、Skynet、Lua、物理依赖；在独立目录构建，用 Skynet Lua service 加载 C 模块；审计每个进程级状态与清理路径。
2. 建立共享输入/固定初始位置，运行 8 项带断言的物理用例；单独区分引擎的碰撞求解和车辆控制。
3. 在同一个 Skynet 进程内创建多个独立 Room service；验证状态一致/隔离、异常和清理。使用普通 Space。
4. 固定时间步，单调时钟给每一步定位，记录每个房间步进和排队延迟；十组 60 秒压测，另做同样负载的纯 Lua 对照。
5. 汇总原始日志、参数、平台限制和实测结论，打包交付，不修改现有游戏和发布流程。
