## 运行说明
前端dist仅随原始交付包提供，本源码仓库不包含dist；请先在client目录执行npm ci && npm run build。需要可运行的Skynet。设置SKYNET_ROOT为你的skynet-demo/vendor/skynet目录后执行server/run.sh，在同一机器浏览器访问http://127.0.0.1:18080。两位玩家使用不同浏览器配置/隐私上下文。默认仅回环监听，手机不能直接连接；公网或局域网部署需另行配置并验证。

当前是单房间、单地图、内存局状态的原型；没有账号注册。暂以全图快照实现8人验证，并未为了此规模强行启用AOI裁剪；AOI模块可用性已独立验证。
