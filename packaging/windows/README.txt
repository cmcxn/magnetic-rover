磁力小车 Windows x64 便携发布包

适用 Windows 10/11 x64。无需安装 Docker、Node.js、Lua 或编译工具。
必须先解压整个 ZIP；不要直接在压缩包中双击运行，也不要混用旧版 DLL。

启动：
1. 双击 start.bat，保持服务窗口打开。
2. 双击 open-game.bat，或在浏览器打开 http://127.0.0.1:18080/ 。
3. 局域网手机或其他电脑连接同一网络，打开 http://本机IPv4地址:18080/ 。
   在命令提示符运行 ipconfig 可查看 IPv4 地址。
   Windows 首次提示防火墙权限时，按实际网络允许专用网络访问。
4. 两位玩家加入同一房间并全部准备，即可开局。
   同一电脑测试多个玩家，请使用不同浏览器或独立浏览器配置。
5. 在服务窗口按 Ctrl+C 停止。关闭窗口也会结束服务；房间和分数只保存在内存中。

默认速度 480，默认监听 0.0.0.0:18080。端口被占用时，先停止占用服务。
仅允许本机访问：在 cmd 中运行 set ROVER_BIND=127.0.0.1，再运行 start.bat。
调整速度：在 cmd 中运行 set ROVER_BASE_SPEED=240，再运行 start.bat（支持 1–480）。
登录页如果记住了旧服务器地址，请修改为 ws://本机IPv4地址:18080/ws 。

文件校验：
根目录 SHA256SUMS 列出包内每个文件的 SHA-256；BUILD-INFO.json 记录游戏版本、
工作区是否有未提交内容，以及所使用 Windows runtime 的原始版本信息。
完整运行时许可与上游说明位于 runtime/licenses、runtime/README.txt；游戏许可见 licenses。

发布验证边界：
打包时运行前端测试与构建，并检查原生文件为 Windows x64 PE、ZIP 完整性与文件校验值。
Windows 真机上的启动、浏览器画面、触控及防火墙行为仍需在目标电脑验收。
